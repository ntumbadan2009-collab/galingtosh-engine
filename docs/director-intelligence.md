# Director Intelligence — creative direction and delivery
- Complete autonomous missions retain narration, verified real media, strict visual relevance and continuity.
- Gemini receives a capability-aware artistic policy throughout conversation, creative brief and editing. Default shot length 3–5s; every shorter shot needs a concrete reason in an independent plan review. Longer shots follow the existing conservative full-scene evidence exception.
- When the director requests rendering, the server records a review request, evaluates all scene/shot batches in independent bounded production ticks, and only allows the requested render after every current-revision batch passes. Exact film/version/revision hash invalidates stale receipts. Review covers narrative, visual choices, rhythm, sound design, continuity and audience comprehension. Corrections are handled through existing film operations and reviewed again. TTS alignment that changes the film invalidates the approval; no stale approval is reused. The queue RPC is still the existing one; this is not an atomic SQL artistic-approval gate.
- Final MP4 image sampling reviews relevance, readability and composition, including neighboring shots within each contact sheet. Existing bounded automatic visual repair is preserved. Audio is checked via actual decoded soundtrack LUFS/true peak: missing/unmeasurable audio and high peaks block cinematic delivery; unusual average loudness is advisory. No fabricated semantic listening or continuous video review.
- No arbitrary visual effects, custom fonts/palettes beyond actual engine capabilities, false retention scores, media generated by AI, forced music, or per-scene media quotas.
- Remaining validation: real configured Gemini calls on an authenticated production; motion/audio semantic review, word-level sync, exact post-synthesis frame timing, atomic queue binding, richer automatic repairs and client UX. The existing operation budget still applies. CI fixture successes are not a real-provider or artistic certification.
